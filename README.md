# Customer Segmentation Using RFM

        Customer segmentation using RFM analysis and clustering algorithms
        on the Online Retail II dataset.

        ## Experiment Outputs

        The `outputs/` directory contains:
        - Clustering benchmark results
        - K-Means, Agglomerative, DBSCAN, and HDBSCAN results
        - RFM segment profiles and validation results
        - Experiment summary and data cleaning funnel
        - Visualizations in `outputs/figures/`

        ## Dataset

        The project uses the Online Retail II dataset.
        The raw dataset is not included in this repository.

        ## Results

        Refer to `outputs/experiment_summary.json` and the CSV files
        for the recorded experiment results.
